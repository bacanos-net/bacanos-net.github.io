## Como Contribuir

1. Faça um fork deste repositório
2. Crie um branch para suas alterações (`git checkout -b feature/nova-feature`)
3. Commit suas mudanças (`git commit -m 'Adiciona nova feature'`)

5. Abra um Pull Request
